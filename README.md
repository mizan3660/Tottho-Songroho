# Tottho-Songroho

**তথ্য সংগ্রহ — তথ্য সংরক্ষণ, অনুসন্ধান ও ব্যবস্থাপনার Android অ্যাপ**

## বর্তমান MVP
- বাংলা Android interface
- নতুন ব্যক্তির তথ্য যোগ করা
- নাম দিয়ে Search
- বিস্তারিত Profile দেখা
- তথ্য ডিভাইসে সংরক্ষণ
- তথ্য মুছে ফেলা

## পরবর্তী সংস্করণ
Public profile ও একাধিক ডিভাইস থেকে একই তথ্য দেখানোর জন্য secure online database/API যুক্ত করা হবে।
